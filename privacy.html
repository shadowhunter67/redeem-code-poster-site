Privacy Policy

Last updated: 26 November 2026.

Who uses this tool

Redeem Code Poster is a personal tool used only by its owner, to publish to the owner's own channels. It has no public sign-in and collects no data from visitors or viewers.

YouTube API Services

The tool uses YouTube API Services with the permissions youtube.upload, to upload videos to the channel its owner authorised, and youtube.force-ssl, only to post a comment with the redeem links under its own videos. It does not read channel data, comments, subscribers or viewer information. By using it, the owner agrees to the YouTube Terms of Service. See also the Google Privacy Policy.

What is stored

  • The OAuth client credentials and refresh token, kept as encrypted GitHub Actions secrets.
  • A list of which redeem codes have been posted and when. It contains no personal data.

No Google user data is sold or shared with third parties. Short-lived access tokens are used in memory only.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. The stored credentials are then deleted from the repository secrets.
